
# Frontend design workflow

When creating or modifying frontend UI:

1. Use `design-taste-frontend` to establish the visual direction, typography, layout, spacing, and motion.
2. Use `no-ai-slop` to review the resulting interface and eliminate generic AI design patterns.
3. Resolve conflicts in favor of the project's existing design system and explicit user requirements.
4. Test desktop and mobile layouts before finishing.
5. Do not redesign unrelated components.

Both skills should be considered for every frontend design task.
